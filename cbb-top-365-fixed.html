OPEN METHODOLOGY

How CBB Top 365 works

Ratings currently use your original custom weighted formula, without recalibration. Higher scores rank higher.

Current rating formula

2.7×Off + 3.3×Def + 12×(W−L)/max(1,W+L) + 2×SOS − 10×Luck − (Tempo−71.6)²/25 + 2×Q1W + 0.75×Q2W − 2×Q3L − 3×Q4L + 0.5×RoadW

Both EvanMiya offensive and defensive ratings are assumed to be better when higher. KenPom SOS is assumed to increase for harder schedules, and luck is assumed to be expressed as a decimal. Confirm the direction and scale of each imported statistic before interpreting the ratings.

These weights are experimental. They are not validated game prediction probabilities. Future work should test historical out-of-sample prediction accuracy and account for overlap between strength of schedule, Quad wins, and road wins.

DATA CONNECTION

Connect Google Sheets

Publish your rankings tab as CSV, paste its public CSV URL below, and load it. The website reads columns A–N in your existing order. Never publish private information in this sheet.

Spreadsheet CSV URL

In Google Sheets: File → Share → Publish to web → choose the rankings sheet → Comma-separated values (.csv) → Publish. If your browser blocks access, use a public CSV file hosted alongside this website instead. Your CSV must have the first 14 columns: Team, Rating, Wins, Losses, Offense, Defense, SOS, Luck, Tempo, Q1 Wins, Q2 Wins, Q3 Losses, Q4 Losses, Road Wins.
